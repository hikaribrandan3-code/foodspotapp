## COLOR PALETTE (Final)

### Primary:
```css
--void: #090B09;        /* Near black, base */
--cream: #E4E0D1;       /* Warm cream, text/accents */
--umber: #3D2817;       /* Deep wood brown */
```

### Accents:
```css
--brass: #B48869;       /* Muted gold, CTAs */
--forest: #1B4D3E;     /* Deep green, subtle use */
--leather: #8B4513;    /* Saddle brown, textures */
--chrome: #C0C0C0;     /* Metallic highlights */
```

### Usage:
- **90%** — Void (backgrounds)
- **8%** — Cream (text, cards)
- **2%** — Brass (buttons, highlights)
- **<1%** — Forest green (subtle borders, hover states)

## ANIMATION MICRO-INTERACTIONS

### 1. The "Entry" Animation
- User clicks "Enter"
- Wood doors slide open (or velvet curtain parts)
- Warm light spills out
- Site reveals with golden hour glow

### 2. Hover States
- Buttons: Fill with brass color, text stays cream
- Cards: Subtle lift (translateY -4px), shadow deepens
- Links: Underline draws from left to right

### 3. Scroll Effects
- Parallax: Background moves slower than content
- Reveal: Sections fade up as they enter viewport
- Progress: Reading progress bar (brass color)

### 4. The "Seal" Moment
- Logo/badge has subtle breathing animation (scale 1.0 → 1.02)
- On hover: Light sweep across (like chrome reflection)
