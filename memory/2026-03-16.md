## 🔴 CRITICAL FINDINGS (Must Fix Before Launch)

### 1. SUPABASE ANON KEY EXPOSED
- **Location:** `src/lib/supabaseClient.js`
- **Risk:** Key hardcoded in frontend bundle enables enumeration attacks
- **Fix:** Move to env vars, rotate key immediately

### 2. GUEST TOKEN CROSS-TENANT LEAK
- **Location:** `src/lib/supabaseClient.js` (Global fetch interceptor)
- **Risk:** Same token sent across all tenants, potential order history leakage
- **Fix:** Scope tokens per tenant: `fs_guest_token_${tenantSlug}`

### 3. MENU MANAGER HERO ITEM COLLISION
- **Location:** `src/pages/owner/MenuManager.jsx` ~L830
- **Risk:** Hero items use non-tenant-scoped IDs (`hero-${index}`), causing cross-tenant overwrites
- **Fix:** Use `\`${targetBusinessId}-hero-${index}\``

### 4. KDS 5-SECOND POLLING NO BACKOFF
- **Location:** `src/pages/staff/StaffKDS.jsx` ~L25
- **Risk:** 720 requests/hour per screen, potential rate limiting
- **Fix:** Implement exponential backoff or Supabase real-time

### 5. MISSING RLS ON `transition_order_state` RPC
- **Location:** `src/pages/staff/StaffKDS.jsx` ~L45
- **Risk:** Potential cross-tenant order manipulation if SQL function lacks business_id check
- **Fix:** Audit SQL function to validate business_id internally

### 6. FOODSPOT AI NO OFFLINE FALLBACK
- **Location:** `src/pages/owner/FoodSpotAI.jsx` ~L115
- **Risk:** Complete dependency on Pollinations AI uptime
- **Fix:** Cache generated images in Supabase Storage
