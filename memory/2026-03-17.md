## Session: Delta UI Fix Plan Creation

**Context:** User requested pixel-perfect 1:1 replication of Delta GBA emulator UI for HikariBoy arcade.

**Key Analysis Sources:**
- Gemini Pro analysis of visual differences
- Claude Sonnet 4.5 priority recommendations
- Direct image comparison of Delta vs HikariBoy

**Critical Fixes Identified:**

### 1. L/R Shoulder Buttons (NEW SPEC)
- Width: 27-28% of shell (was 18-20%)
- Height: 4-5% of shell (was 6-7%)  
- Gap: ZERO (flush to top edge)
- Shape: Long stretched pill curving inward toward brand
- Color: Light gray (not dark)

### 2. Menu/Select/Start (Highest Priority)
- Change from: Large dark pills with text inside
- Change to: Small 28px circles with labels BELOW

### 3. D-Pad
- Change from: 4 separate buttons
- Change to: Single cohesive cross piece with sunken center indent

### 4. A/B Buttons
- A larger and HIGHER than B
- Semi-transparent white background
- Thin font (300 weight)

### 5. Layout
- Screen:Controller ratio 60:40 (currently 50:50)
- Add black mid-bar gap with HIKARIBOY logo
- Controller color: Purple (#8B5CF6) not red

**Next Steps:** Implement all fixes per priority order in the plan file.
