### Emulator Setup (CORRECTED)

**Initial CDN URLs were wrong (404 error).** Fixed to use real package:
- **mGBA-wasm:** `@thenick775/mgba-wasm@2.4.1` from jsDelivr
- This is the same core that powers gbajs3

**Button mapping:**
```javascript
const BUTTONS = { A: 0, B: 1, SELECT: 2, START: 3, RIGHT: 4, LEFT: 5, UP: 6, DOWN: 7, R: 8, L: 9 };
```

All games support:
- PostMessage BUTTON_PRESS API
- SELECT to exit (most games)
- START to exit (μCity)
- PAUSE/RESUME messages
- Auto-ROM detection (shows "ROM NOT FOUND" if missing)

**Note:** mGBA-wasm requires cross-origin isolation headers for full functionality:
```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```
