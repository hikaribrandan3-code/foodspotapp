# March 24, 2026 - Late Night: Settings.jsx Color Revert Bug Hunt

## Context
User reported color revert bug persists - clicking hero icon, picking color, confirming, saving → reverts back. This is the 5th+ attempt at fixing this bug.

## Root Cause Analysis

### Initial Approach (FAILED)
- Tried CSS variable capture before async operations
- Tried inline style reading instead of getComputedStyle
- Tried default fallbacks in payload

### The Real Problem Found
**Two separate issues:**

1. **Theme colors (primary, secondary, etc.):**
   - `Object.assign(tenant, updates)` mutates context directly
   - `refreshTenantData()` overwrites with stale DB data (replica lag)
   - useEffect syncs local state from tenant when `!hasChanges`

2. **Hero icons:**
   - `handleHeroIconColorUpdate` updates `heroIconColors` local state ✓
   - But save payload uses `tenant?.hero_icons` (stale) ❌
   - ColorPillar reads from `tenant` not local state ❌

## Fixes Applied (4 commits)

### Commit c68bee4: "use local state for theme colors (munchboy pattern)"
- Added `localThemeColors` state object
- Sync from tenant on load (only when not dirty)
- Update local state immediately when color changes
- Save uses `localThemeColors` directly

### Commit 4c3d19d: "prevent useEffect from overwriting colors after save"
- Added `justSavedRef` flag
- Set before `refreshTenantData()`
- useEffect skips sync if flag is true
- Prevents stale DB data from overwriting local state

### Commit cd42ca6: "ColorPillar and navbar preview now read from localThemeColors"
- ColorPillar now maps keyName to localThemeColors
- navbarColor reads from localThemeColors
- UI shows live changes instead of stale tenant data

### Commit df56a19: "Hero icons now save from local state (heroIconColors) not tenant"
- Save payload builds hero_icons from `heroIconColors` local state
- Matches pattern used for theme colors and munchboy colors

## Pattern Established
**"Munchboy Pattern" for atomic saves:**
```javascript
// 1. Local state for live changes
const [localColors, setLocalColors] = useState({...})

// 2. Update local state immediately on change
setLocalColors(prev => ({...prev, [field]: value}))

// 3. Save uses local state (never tenant)
payload: { colors: localColors }

// 4. justSavedRef prevents useEffect overwrite
justSavedRef.current = true
await refreshTenantData()
```
