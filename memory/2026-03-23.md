## Bubble Tea Blast Bug Fix - Ceiling Jitter

**Issue:** Bubbles do weird floating/jittering when ceiling drops - they don't settle properly and float around multiple times before settling.

**Root Cause:** In `dropCeiling()` → `updPos()`, bubble positions are updated but their animation physics (wobble, wobbleV, ripOff) persist, causing the jitter/float effect.

**Fix Required:** Update `updPos()` function to reset animation offsets:
```javascript
function updPos(){
    for(let r=0;r<grid.length;r++)
        for(let c=0;c<grid[r].length;c++)
            if(grid[r][c]){
                const p=bobaXY(r,c);
                grid[r][c].x=p.x;
                grid[r][c].y=p.y;
                // Reset animation offsets so bubbles don't jitter
                grid[r][c].wobble=0;
                grid[r][c].wobbleV=0;
                grid[r][c].ripOff=0;
            }
}
```

**Secondary Issue:** In `Boba.update()`, `this.wobbleV-=.8` is problematic (should be damped differently), but the reset fix above addresses the immediate symptom.

**Status:** Fix identified, pending user confirmation to apply.
