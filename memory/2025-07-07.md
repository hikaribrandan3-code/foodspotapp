# 2025-07-07 - Arcade Unification

## Summary
Fixed critical Arcade issues and unified the game experience into a single scrollable feed.

## Problems Solved

### 1. Camera Opening Bug
- **Root cause**: BottomNav (with camera button) was rendered on all customer routes including `/arcade`
- **Fix**: Added `!pathname.includes('/arcade')` check in App.jsx to hide BottomNav on arcade page
- **Also added**: Click capture layer in Arcade.jsx to prevent event bubbling

### 2. Wrong Game Component Deployed
- **Root cause**: Two GameHero-EASY.jsx files existed - one in `/src/components/` (old/broken) and one in `/grubclub/` (new/fixed)
- **Fix**: Replaced the broken component with mobile-optimized version including:
  - Mobile touch CSS: `touchAction: 'manipulation'`
  - Proper iframe sandbox permissions: `allow-scripts allow-same-origin allow-pointer-lock`
  - Swapped desktop games (Tetris, Pac-Man) for mobile games (Hextris, Clumsy Bird)

### 3. Unified Arcade Experience
- **Before**: Toggle between "ARCADE" (custom games) and "QUICK GAMES" (external iframes)
- **After**: Single scrollable feed with all 16 games in 9:16 format
- **Games**: 10 custom local games + 6 external quick games (2048, Hextris, Stack, Clumsy Bird, Tic Tac Toe, Connect Four)
- **Visual distinction**: Local games use image covers (blue button), external games use emoji covers (purple "⚡ PLAY NOW" button)
- **External games**: Launch in fullscreen iframe with ✕ close button

## Files Modified
- `src/App.jsx` - Hide BottomNav on arcade routes
- `src/components/GameHero-EASY.jsx` - Mobile-optimized game component
- `src/pages/customer/Arcade.jsx` - Unified scrollable game feed (complete rewrite)
