## Hero Cover Image System - Major Fixes Applied

### Issues Found & Fixed:

**1. Navbar Color Not Applying (Commit `c85bc58`)**
- Root cause: App.jsx hydration effect was missing `navbar_color` in branding object
- Initial state had it, but tenant data load overwrote it
- Fix: Added `navbar_color` and `nav_icon_mode` to branding hydration

**2. Info Pills Hardcoded Colors (Same commit)**
- Info.jsx had hardcoded hex values (#E55F51, #F4D03F, etc.)
- Settings saved to DB but frontend never read them
- Fix: Refactored Info.jsx to read from `config.infoPills` with saved colors

**3. Camera Icon Color (Commit `56074cd`)**
- Camera icon stayed black when nav set to white on black navbar
- CameraIcons.jsx components ignored style prop
- Fix: All 4 camera icons now accept and forward `{ style }` prop

**4. CoverImageEditor Crash (Commit `4fbff31`)**
- Error: `i.branding is undefined`
- Settings.jsx wasn't passing config prop to CoverImageEditor
- Fix: Added `config={{ branding: { logo_url: null } }}`

**5. Overlapping Old Image in Preview (Commit `5d58c37`)**
- Preview step showed old hero as tiny logo overlapping new hero
- Was passing `draft.hero_url` as `logo_url` in config
- Fix: Changed to `logo_url: null`

**6. Hero Transform Params Not Parsing (Commits `a73384e`, `4873a52`)**
- Scale/offset saved in URL (?s=2&x=-100&y=0) but never parsed for display
- Frontend showed image at default scale (1x)
- Fix: Added `parseHeroUrl()` helper, applied in App.jsx and Menu.jsx

**7. CSS Overriding Dynamic Values (Commit `309be69`)**
- `.menu-header-bg` had `background-size: cover !important`
- This overrode dynamic scale from editor
- Fix: Removed !important from CSS, AppHeader sets backgroundImage inline

**8. Menu.jsx Wrong Config (Identified, not yet fixed)**
- Menu.jsx passes `tenantData?.app_config` directly to HeaderClamp
- Missing parsed scale/offset values
- Other pages (Home, Info) pass normalized `config` object
- **Pending fix:** Change to `<HeaderClamp config={config} />`

### Editor Improvements:
- Added file size warning for images >500KB
- Added upload guidelines (1200×800px, 16:9, <500KB)
- Increased min zoom from 50% → 25% for tall images
- Removed zoom buttons (touch pinch works)
