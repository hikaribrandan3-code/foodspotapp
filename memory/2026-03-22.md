## Bubble Tea Blast Performance Audit

**Status:** Fixes identified but NOT YET APPLIED (Claude hasn't pushed)

### Issues Found
1. **Gradient Factory** - 7 gradients created every frame (GPU thrashing)
2. **Double Grid Scan** - 416 iterations/frame in danger bar + highlight
3. **6 Particle Arrays** - Separate loops causing overhead
4. **Parallax Always Running** - Even during pause/splash

### Fixes Decided (A, B, D)
- **A. Cache gradients** - Only rebuild when combo changes > 0.05
- **B. Track lowestRow** - Variable instead of scanning 208 grid cells
- **D. Skip parallax when paused** - Don't update when gameState !== 'playing'
- **C (Skipped for now)** - Merge particle arrays
