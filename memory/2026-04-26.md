### Mercado Pago Audit (CRITICAL)
Discovered 6 bugs causing MP payments to silently fall back to cash:
1. Wrong webhook URL (pointed to old `mercadopago-handler` instead of `mp-webhook`)
2. Old webhook used global token (breaks multi-tenant)
3. Silent cash fallback in `Order.jsx` catch block (hides errors, patches to cash)
4. `mp-webhook` expected `branding_secrets` table which may not exist
5. Order status inconsistency (`paid_unreleased` vs `released_to_kitchen`)
6. `back_urls` path mismatch potential
