## Second Pre-Compaction Session - Layout Fix Failures

### Option 1 Failed (Canvas 100% width/height)
**Attempt:** `canvas.style.width='100%'; canvas.style.height='100%'`
**Result:** Black screen - broke the game rendering
**Why:** Canvas scaling with DPR + 100% CSS caused rendering issues

### Option 2 Applied (Margin Auto Centering)
**Fix:**
- `canvas.style.width=W+'px'` (fixed 390px)
- `canvas.style.height=H+'px'` (fixed 520px)
- `canvas.style.margin='0 auto'` (CSS centering)
- `canvas.style.display='block'` (required for margin auto)

**Pending:** User testing to verify centering works

### Pattern Identified
- Option 1 broke rendering (black screen)
- Option 2 keeps working render but attempts proper centering
- Container is already centered via `left: ((window.innerWidth-w)/2)`
- Canvas just needs to center inside that container

**Commit:** `2d7ee1c` - "fix: center canvas with margin auto (revert 100% width)"
