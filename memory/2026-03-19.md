### Spice Invaders Debug Session
**Bug:** Ship auto-moves right without touching D-pad
**Root Cause:** Lines in `update()` method forcing `inp.RIGHT = true` based on `_rHeld` flag:
```javascript
// These lines override HikariBoy message handler:
if(this._lHeld)this.inp.LEFT=true;
if(this._rHeld)this.inp.RIGHT=true;
if(this._zHeld)this.inp.A_PRESSED=true;
```
**Solution:** Comment out/remove those 3 lines. Message handler already sets inputs correctly.
