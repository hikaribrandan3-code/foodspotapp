
## UGC Camera Activation — Audit & Bug Fixes (May 3, 2026)

### Bugs Fixed
1. **`useMemo` undefined** — `CameraActivationBanner.jsx` referenced `useMemo` without importing it. Fixed by replacing with a simple `Math.floor()` random variable.
2. **Supabase `.catch()` chain** — `supabase.from().update().eq().eq().catch()` is not valid (PostgREST builder has no `.catch()`). Fixed all 3 instances in `useCameraActivation.js` by adding `.then(() => {}).catch(() => {})`.

### New Character: `BurgerChar`
- Canvas-based walking hamburger with sesame seed sprinkles
- Anime eyes, waddle walk-in, DSLR camera with flash
- Speech bubble: "Burger time! Want to take a foto? 🍔📸"
- Files: `src/components/Camera/BurgerChar.jsx`, `BurgerChar.css`

### 4-Character Rotation System
- Counter stored in `localStorage` key `fs_banner_counter`
- `% 4` mapping: `1=Luffy`, `2=Naruto`, `3=BurgerChar`, `0/4=donut`
- Uses `useEffect` (not `useMemo`) to guarantee single increment per mount

### Critical Finding: `ugc_activations` table MISSING
- Supabase returns **404** on all queries to `ugc_activations`
- Migration file `20250317000000_add_ugc_activations.sql` is missing/empty
- This causes `loadState()` to 404 and `handleTriggered()` upsert to 404
- **Impact:** Theoretically the hook continues past the 404, but this is likely why no banner ever renders in practice
- **Need:** Create the table or handle 404 gracefully in the hook

### Safari Debugging Notes

### Character Rotation Bypass Bug
- `characterMode === 'luffy'` returns `<ChibiLuffy />` BEFORE the `!propIsVisible` check
- Same for Naruto and BurgerChar — they would render even if `showBanner=false`
- Not the root cause of "nothing shows" but a logic flaw
